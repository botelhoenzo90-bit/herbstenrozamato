# Mídias do site — Herbsten Rozamato Sousa

Esta pasta é reservada aos arquivos reais que serão usados no site. O carrossel permanece temporariamente com cartões somente de texto até que as mídias sejam adicionadas.

## Arquivos previstos

- `herbsten-retrato.jpg` — foto profissional de Herbsten.
- `herbsten-formatura.jpg` — foto real da formatura.
- `video-atendimento.mp4` — vídeo explicando como funciona o atendimento.
- `video-abordagens.mp4` — vídeo explicando as abordagens de trabalho.

## Como adicionar

Envie os arquivos nesta pasta pelo GitHub usando **Add file → Upload files** e faça o commit na branch `main`.

**Importante:** use apenas fotos e vídeos autorizados pelo profissional. Não substitua a foto da formatura por uma imagem genérica que possa ser confundida com uma foto real.

Depois que os arquivos forem enviados, atualize os caminhos dos arquivos no código para exibi-los no carrossel.
